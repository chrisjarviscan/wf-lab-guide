# Lab Guide for Applied AI Labs for Nonprofits

Ask your own Claude about the labs: dates, what to bring, kit steps, homework and program rules. The guide answers from participant materials and starts program answers with its version so you can check it.

**Current version: Lab Guide 1.0.3 · Oct 5, 2026**, built from the pages published on Oct 5, 2026.

**Joining today's lab? [Start here](START-HERE.md).** Facilitators: [opening script and run-through](FACILITATOR-RUN-THROUGH.md).

## Add the guide in five minutes

You are adding the program's guide to Claude. This does not connect your private chats or `AI-Labs` work folder to GitHub. You do not need a GitHub account to read this public repository or download its guide files. Your questions and uploaded files go to Claude in your own account, subject to your organization's settings and policies.

Choose the route your Claude actually offers. Screen labels can change; a paid plan alone does not establish that Plugins or Skills are available. If a control is missing or blocked, use the attachment route. Stop installation troubleshooting after five minutes and move on to the kit.

### A. GitHub plugin, if Plugins are available

1. In Claude's desktop app, open **Customize → Plugins**, if offered. Use **Add → Add marketplace → Add from a repository**, or the equivalent repository option shown in your app.
2. Enter `chrisjarviscan/wf-lab-guide`, then add **wf-lab-guide** from that marketplace.
3. Open a fresh session for guide questions. If `/` offers **lab-guide**, choose it; otherwise explicitly ask Claude to use the Lab Guide.
4. Run the check below. Installation alone does not show that the current guide loaded.

If those controls are absent, use B. Browser plugin availability and plan eligibility should be checked in [Anthropic's current help](https://support.claude.com/), rather than inferred from the plan name.

### B. One attachment, if files can be uploaded

1. Download [lab-guide-chat.md](https://raw.githubusercontent.com/chrisjarviscan/wf-lab-guide/main/download/lab-guide-chat.md). If it opens as text, save the page as `lab-guide-chat.md`.
2. Start a fresh Claude chat, outside your AI-Labs Project, and attach that file with Claude's file-upload control.
3. Paste the check below. Keep that chat for guide questions. In another new guide chat, attach the file again.

This file contains the guide and its participant sources. It does not install a persistent skill or update itself. Download a fresh copy after a release. If uploads are unavailable, use the limited [copy-prompt](download/copy-prompt.md) for dates and main rules, and open the participant kit for its steps.

### C. ZIP skill, if Skills are available

1. Download [lab-guide.zip](https://raw.githubusercontent.com/chrisjarviscan/wf-lab-guide/main/download/lab-guide.zip). Keep it zipped.
2. If Claude offers **Settings → Capabilities → Code execution and file creation**, turn that on if your organization's policy allows it.
3. Open **Customize → Skills** and use **+ → Create skill → Upload a skill**, or the upload option shown in your account. Select `lab-guide.zip` and enable **lab-guide**.
4. Start a fresh chat, select **lab-guide** from `/` if offered, and run the check below.

If the required controls are absent or blocked, use B. After an update, replace the old uploaded skill with the new ZIP, keep only one enabled copy, and rerun the check.

## Check the guide loaded

In the fresh guide chat/session, paste this harmless question. Attach the file first if you chose B.

```text
Use the Lab Guide (the attached file, if present). I am in the Monday cohort. Which lab is on October 5, and what time is it? Name the source you used. Do not read or change my work files.
```

The answer must start with **Lab Guide 1.0.3 · Oct 5, 2026** and say **Lab 2: Writing and the org brain; Monday, October 5, 12:00 to 1:30 PM Central**, citing the Lab 2 kit or program schedule. Compare the stamp with the one at the top of this page. A missing stamp, wrong version, guessed source or wrong time is a failed check.

Then check that it can read the full kit:

```text
Show me the exact Lab 2 setup readback prompt, and tell me where to run it in the browser.
```

Expect the prompt `Read AGENTS.md first. What did I ask you to follow in this folder? Name the three rules that matter most.` and instructions to use a new chat **inside your AI-Labs Project** with current files. Your guide chat stays outside the Project; your exercise chat goes inside it.

If it fails: start fresh, make sure the guide is enabled/selected or the current attachment is present, and try once more. For an older plugin, use its update control if offered; if it remains old, remove and re-add the plugin or use B. For an older ZIP, replace it and disable the old copy. For an older attachment, start a new chat with the newly downloaded file. Do not assume GitHub updates have reached your Claude automatically.

## Use it during the lab

Ask guide questions in a fresh chat outside your AI-Labs Project. Do the exercise in your own `AI-Labs` Cowork session or Project, following the kit. The [start page](START-HERE.md) has today's readback and readiness checks.

Clients, donors, volunteers and anyone you serve never go into Claude or your AI-Labs folder, and neither do health or case details. Passwords, account numbers and personnel matters stay out too. Your organization's own policy comes first. Installing this guide does not grant RW Institute or PCI access to your private Claude chats or work files.

If you get stuck, email Nichole Giller at nichole@realizedworth.com with the step, guide version and what you see. Check screenshots for sensitive information before sharing them.

The guide runs inside your own Claude account. Adding these files carries no separate guide charge; questions use your Claude usage like other chats.
