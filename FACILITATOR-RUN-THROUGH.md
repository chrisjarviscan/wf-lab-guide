## Minute 2–3: check

> Check my Lab 4 access.

Pass: the first line says the [current README version](README.md) (1.0.35 or later runs Lab 4), Claude quotes a line from the Lab 4 kit, and it lists the Lab 4 files it can see by name only. Names alone are correct here: the check never opens data files, and never a file with "key" in its name. Check that yourself. A version line alone is not a pass.

Not sure the guide is loaded at all? Ask **“Is the guide working?”** first.

**Older version in the first line?** On 1.0.34 or older, update before the begin phrase. GitHub Project: open the repository item in Project files and choose **Sync**. Attachment: download and attach `lab-guide-chat.md` again. Desktop: download `lab-guide.zip` again and upload it in Customize → Skills, replacing the old one.

## Minutes 3–5: begin

> I'm ready to begin Lab 4.

“Answer one question at a time. Claude tells you which steps you do by hand: deleting notes, swapping names with your key and counting. You decide every change it proposes.”

Claude leads: heading check → by-hand steps → brief → 10 rows with a change log → your check → the rest → cleanup recipe saved.
A name slipped through the swap? Claude stops and gives row numbers. The fix goes in the swapped file in `Working`: give an organization its placeholder (and add that spelling to the key) or delete a person's name. Never the preparation copy, which Claude does not read. Then start step 4 fresh.
Ten minutes left in the room: **We have ten minutes left. Save where I am and tell me what's left.** Claude saves the furthest checked point and lists the rest as this week's work.
Optional setup help: **Check and fix setup.** Help individuals; continue the existing agenda at five minutes.

Before every fresh chat, the swapped file and `AGENTS.md` must be available in that chat. Downloads do not automatically update local or Project files. Practice stays separate from real data.
