## Opening script — ten minutes maximum

Use this within the existing opening, with the installation attempt capped at five minutes. Ready participants continue into the kit while others receive help. If time gets tight in the breakout, protect the saved voice notes and updated `AGENTS.md` before the draft; finish the real piece afterward.

**Minute 0–1.** “Today we'll make voice notes and a real draft or an RFP matrix. First we'll add the Lab Guide and check its answer. It answers program questions in your own Claude. Adding it doesn't connect private work or chats to GitHub, and you don't need a GitHub account.” Post the start message below and demonstrate the route that passed your run-through.

**Minute 1–5.** “If desktop Claude shows Plugins, add this repository and select wf-lab-guide. If that option isn't there, use the single attachment in a fresh chat. Keep guide questions outside your AI-Labs Project. Paste our check and compare its version and answer with the page.” Participants type **guide ready** only when it passes. At five minutes, move anyone still troubleshooting to attachment or direct kit; a facilitator can assist while the exercise continues.

**Minute 5–8.** “Now open a new Cowork session on AI-Labs itself, or a new chat inside your AI-Labs Project. This is where you do the work. Paste the readback test. Check each rule against AGENTS.md.” If Projects are unavailable, use a normal browser chat with current files attached. Missing homework is a help request; participants can use today's practice pack.

**Minute 8–10.** “Have the Lab 2 kit and practice pack in Kits. Choose public documents or the fictional practice pack. We'll save voice-notes.md, draft a piece, open the saved draft, and start fresh from those files. Keep client, donor, volunteer, health and case details out, along with passwords, account numbers and personnel matters. Your organization's policy comes first.” Begin the kit.
