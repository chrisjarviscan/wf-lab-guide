# A safe five-minute practical test

Use this fictional example to test the guide's practical help without providing private materials. This exercise is optional and does not change today's lab agenda.

1. Add the current guide using the main repository's README and complete its connection check.
2. In your permitted work session, attach or paste [the fictional transcript](transcript.md). If you use an ordinary chat rather than an installed guide, include the current guide attachment there too; a separate chat cannot see it automatically.
3. Ask:

```text
Use the Lab Guide's practical transcript-to-PowerPoint workflow. This is a fictional transcript. The audience is our board, and the purpose is to decide whether to pilot the proposed newsletter. Make a four-slide outline first, with speaker notes and paragraph references. Distinguish proposals from decisions. Use a restrained, readable design; treat it as a proposed design, not an approved brand. Tell me what is missing and whether this session can make an editable PowerPoint. Wait for me to check the outline before creating the file.
```

4. Compare the answer with [what the transcript actually supports](expected-checks.md). Approve or correct the outline. Then, if the session can make files, ask it to create the editable `.pptx` from that approved outline.
5. Download/open the actual PowerPoint and check editing, layout and speaker notes. Without file tools, a complete outline is the fallback; it must not claim to have created a PowerPoint.

Passing evidence: a correct outline, honest tool limits, the actual requested file when supported, and a file you can open. A filename or an invented download link alone is not passing evidence. We have checked the fixture and package; your Claude account's real answers and file creation are a separate live test.
